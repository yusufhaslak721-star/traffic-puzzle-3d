# Traffic Puzzle 3D

Mobile-first 3D traffic puzzle game by KARAGAMESTUDIO.

Tap vehicles in the correct order and clear the road network without collisions.

## Technical direction
- Three.js / WebGL
- Touch-first Android gameplay
- Authored vehicle routes: cars never improvise or leave their intended road
- Data-driven handcrafted levels
- Collision/puzzle logic separated from rendering and decoration
- Responsive mobile runtime ready for later Android WebView packaging

## Initial milestone
Build a polished playable vertical slice first, then expand the same systems into increasingly difficult handcrafted levels.
